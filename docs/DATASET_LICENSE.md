## 三、为什么不能上传

1. **购买 ≠ 获得再分发权。** 电商 / 网盘售卖的数据集，卖家通常只授予「自己用于学习或训练」的使用权，不包含公开传播、二次分发的权利。
2. **数据集的著作权独立于代码。** 即使项目代码是 GPL-3.0 开源，也不能借此把数据集一并开源。
3. **图片含真实人物。** 涉及个人图像的数据还受《个人信息保护法》约束，公开传播风险更高。
4. **标注文件也受保护。** 标注是原作者的劳动成果，同样不能随意再分发。

---

## 四、如果将来想公开数据集

1. **改用自己采集的数据**：自行拍摄 + 自行标注，版权完全归你，可自由公开（建议同时做人物模糊化处理）。
2. **改用可再分发的公开数据集**：例如公开的跌倒检测数据集（多为 CC BY / CC BY-NC 系列）。
   使用时必须保留原始署名，并注明许可名称；注意 `NC` 表示**禁止商用**。
3. **取得书面授权**：联系数据集原作者，取得可再分发的书面许可后再发布。

无论采用哪种方式，都要：

- 不要声称数据集是「原创」，除非确实由你采集标注；
- 给出原始来源链接与许可名称；
- 在 `README.md` 与 [NOTICE.md](../NOTICE.md) 中同步更新说明。

## 五、对模型权重的影响

本仓库发布的 `runs/train/exp4/weights/best.pt` 是**训练产出物**，不是原始图片的副本，
按 GPL-3.0 随项目发布。

> 但需注意：不同法域对「用受版权保护的数据训练出的模型」的定性仍有争议。
> 若你计划将该模型用于**商业用途**，建议自行评估训练数据带来的权利风险。
